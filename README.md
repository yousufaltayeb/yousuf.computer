# yousufcomputer

A personal site based on [Ben Adam's personal-site](https://github.com/benadam11/personal-site). Thanks to [Ben](https://github.com/benadam11) for the original design and inspiration.

## What's different

- **Rebuilt with Next.js** — the original uses Astro; this version is built with Next.js and static export
- **Arabic (RTL) support** — full right-to-left layout, IBM Plex Sans Arabic font, and RTL-aware prose styling for bilingual content
- **TOML frontmatter** — blog posts use TOML (`+++`) instead of YAML (`---`)
- **Different content sections** — replaced the experiments/interactive demos with a work experience and side projects page
- **Bun** — uses Bun as the package manager

## Getting Started

```bash
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
