PATTERN Architects needed a portfolio that felt like an extension of their work, not another architecture template. I built a bilingual website for the Riyadh studio that presents its residential, commercial, hospitality, and master-planning work through a restrained, image-led experience.

The site includes a project index, detailed project pages and galleries, an overview of the firm's services, and a focused contact experience. English and Arabic are treated as two fully composed layouts, with proper RTL behavior rather than a translation layer added after the fact. The interface uses proportion, sequence, and movement to echo the way architects present space while keeping the work itself at the center.

Built with Astro, React, TypeScript, and Tailwind CSS as a fast static site. I also handled responsive behavior, accessible navigation, reduced-motion support, image loading, and the final revision passes with the client across desktop and mobile.
